# CBL-Trailblazer

CBL project for programming.

## Requirements
- Java JDK 17 or newer (only required when running from source).
- A Java-compatible IDE (for running the source code).
- The CBL-Trailblazer project folder.

## How to View Code and Run Game
1. Open the CBL-Trailblazer project folder in a Java-compatible IDE.
2. Open src/main/Main.java.
3. Run Main.java to launch the game.

## How to Launch the Game Directly
1. In CBL-Trailblazer, find TrailBlazer/TrailBlazer.exe.
2. Double-click TrailBlazer.exe to launch the game.
