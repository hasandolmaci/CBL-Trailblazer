# TrailBlazer

TrailBlazer is our CBL project for TU/e. It is a turn-based puzzle game built in Java. You draw paths by walking around a room, leaving arrows behind you. The robots follow those arrows onto pressure plates, triggering the next robot in the chain. Activate all the plates, then reach the exit to finish the level.

## What you need

A Java Development Kit (JDK) 21. The project has been compiled with OpenJDK 21.
A desktop environment, since the game opens in a Java Swing window.

Build and run on Windows

Download and extract the project, or clone this repository. Open PowerShell in the project folder, where you can see `src` and `res`.

Compile the source files:

```powershell
New-Item -ItemType Directory -Force build/classes | Out-Null
$sourceFiles = Get-ChildItem -Path src -Recurse -Filter *.java | Select-Object -ExpandProperty FullName
javac -encoding UTF-8 --release 21 -d build/classes $sourceFiles
```

If the compiler finishes without errors, start the game:

```powershell
java -cp "build/classes;res" main.Main
```

Keep the terminal open while playing. After editing the Java files, run the build command again before starting the game.

## Build and run on macOS or Linux

From the project folder, run:

```sh
mkdir -p build/classes
find src -name '*.java' > build/sources.txt
javac -encoding UTF-8 --release 21 -d build/classes @build/sources.txt
java -cp "build/classes:res" main.Main
```

The classpath separator is `:` on macOS and Linux, and `;` on Windows. The `res` entry is needed so the game can find its resources.

## Playing the game

Read the introduction, continue to the menu and choose the first level. Later levels unlock as you complete the earlier ones.

- **Arrow keys or WASD:** move your character and leave arrows along your route. Walking over a tile again lets you change its arrow.
- **Move blue robot:** start the robot chain after planning your paths.
- **Restart:** reset the current level and try a different route.
- **Solution:** reset the level and display the saved solution arrows. Press **Move blue robot** to run it.
- **Next level:** continue after completing a level.
- **Menu:** return to the level selection screen.

## If something goes wrong

If Java reports that it cannot find `main.Main`, check that the build finished successfully and that you are running the command from the project folder.

If the game reports a missing image, map or font, check that the `res` folder is still present and included in the classpath exactly as shown above. Copying only the compiled classes is not enough to run the game.

## Project folders

- `src/` contains the Java source code.
- `res/` contains the maps, saved solutions, sprites, font and introduction text.
- `build/classes/` contains the classes generated by the build commands above.
- `out/` is the output folder used by the included VS Code configuration. The terminal instructions use `build/classes/` so they compile a fresh copy of the source.
